# 🎙️ ElevenLabs Assistant & TTS Stream Capturer (Userscript)

Автоматический юзерскрипт для браузерных расширений (Tampermonkey / Violentmonkey), предназначенный для полуавтоматической нарезки текста, отправки и мгновенного перехвата/скачивания полных MP3-файлов с веб-интерфейса **ElevenLabs**.

---

## 🔥 Возможности

- **✂️ Автоматическая нарезка текста:** Разбивает длинный текст сказки/истории на логические блоки (до ~900 символов) по предложениям.
- **🚀 1-Кликовая отправка и воспроизведение:** Автоматически подставляет текст в поле ElevenLabs и активирует воспроизведение.
- **🎧 Полносвязный перехват аудио (Stream Reassembler):**
  - Перехватывает `fetch` потоки `audio_base64` в реальном времени.
  - Собирает 100% полный нерасчлененный MP3 файл без обрывов на паузах или запятых.
  - Резервный аккумулятор для `MediaSource` и `WebAudio API`.
- **🛡️ Валидация файлов (Magic Bytes):** Проверяет сигнатуры бинарных заголовков (`ID3`, `MP3 frame sync`, `RIFF WAV`), предотвращая сохранение не-аудио мусора.
- **💻 Встроенный консольный отладчик:** Отображает все перехваченные события сети прямо в интерфейсе на странице.

---

## 🚀 Установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** в ваш браузер (Chrome / Opera / Edge / Firefox).
2. Нажмите на иконку Tampermonkey -> **«Создать новый скрипт»**.
3. Скопируйте содержимое файла [`elevenlabs_assistant.user.js`](./elevenlabs_assistant.user.js) в редактор Tampermonkey.
4. Нажмите **File -> Save** (`Ctrl + S`).

---

## 📖 Как пользоваться

1. Откройте страницу [ElevenLabs Text to Speech](https://elevenlabs.io/app/speech-synthesis) или [ElevenLabs API Demo](https://elevenlabs.io/text-to-speech-api).
2. В правом верхнем углу сайта появится виджет **🎙️ ElevenLabs Assistant**.
3. Вставьте ваш текст в виджет и нажмите **«✂️ Нарезать текст»**.
4. Нажмите **«🚀 Озвучить кусок 1»** — виджет сам отправит кусок на озвучку и скачает готовый `chunk_01.mp3` в папку Загрузки.
5. Жмите **«▶»** для перехода к следующему куску.
